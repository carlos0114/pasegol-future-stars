# Future Stars Platform

Quiero crear PaseGol, una plataforma digital que conecte jóvenes futbolistas (5 a 15 años) con clubes y buscatalentos.

El objetivo es que los chicos puedan crear un perfil profesional, subir sus mejores jugadas y ser descubiertos por personas reales del mundo del fútbol.

PaseGol debe transmitir:

Sueño

Profesionalismo

Oportunidad

Seguridad (porque son menores)

Futuro

2️⃣ Objetivo Principal de la Web

Registro de jugadores

Creación de perfil con datos deportivos

Subida de videos

Visualización por parte de clubes/buscatalentos

Sistema de contacto seguro

3️⃣ Público Objetivo

Primario:

Padres de niños futbolistas

Niños y adolescentes de 5 a 15 años

Secundario:

Clubes de fútbol

Captadores

Academias

Representantes

La web debe estar en español e inglés.

4️⃣ Estructura de la Web

🏠 Home

Debe incluir:

Hero impactante con imagen de niño jugando al fútbol

Frase potente (ejemplo: “El talento no se pierde. Se muestra.”)

Botón CTA:
👉 “Crear Perfil Gratis”
👉 “Soy Club / Buscatalento”

Secciones:

¿Cómo funciona?

Beneficios para jugadores

Beneficios para clubes

Testimonios (a futuro)

Footer completo con redes y contacto

👤 Perfil de Jugador

Debe incluir:

Foto de perfil

Nombre

Edad

Posición

Altura / Peso

Club actual

Ciudad / País

Video destacado (principal)

Galería de videos

Estadísticas básicas

Botón “Contactar”

El diseño debe ser moderno, estilo red social deportiva + toque profesional.

🏢 Panel de Club / Buscatalento

Buscador por:

Edad

Posición

País

Altura

Filtros avanzados

Acceso a perfiles

Sistema de guardar favoritos

🔐 Registro y Seguridad

Necesito:

Registro con email + contraseña

Verificación

Autenticación con JWT

Roles:

Jugador

Padre

Club

Admin

Los menores deben requerir consentimiento del padre.

5️⃣ Tecnología Deseada

Frontend:

React o Next.js

Diseño moderno, rápido y mobile first

Backend:

Node.js

Base de datos (PostgreSQL o MongoDB)

Subida de videos a:

Amazon S3 o Firebase Storage

Hosting escalable.

6️⃣ Diseño Visual

Estilo:

Profesional

Deportivo

Inspirador

Colores sugeridos:

Azul oscuro (confianza)

Verde o amarillo (energía)

Blanco (limpieza)

Debe verse como una mezcla entre:

Red social deportiva

Plataforma profesional de scouting

7️⃣ Monetización (fase 2)

Plan premium para mayor visibilidad

Suscripción para clubes

Destacar perfiles

8️⃣ Objetivo a Largo Plazo

Convertir a PaseGol en la mayor plataforma digital de visibilidad para fútbol juvenil en Latinoamérica.
